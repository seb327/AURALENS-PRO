# Store assets

All assets are generated by [`scripts/generate-store-placeholders.js`](../scripts/generate-store-placeholders.js) — pure Node, no native deps. Regenerate any time with:

```bash
npm run generate:assets
```

The generator now embeds a 5×7 bitmap font so screenshots ship with real, branded text. Final production marketing art (Figma, Photoshop, Adobe Illustrator) can replace any of these files in place — keep the dimensions identical.

## App icon family

| File                          | Dimensions  | Role                                          |
|-------------------------------|-------------|-----------------------------------------------|
| `assets/icon.png`             | 1024 × 1024 | iOS app icon / generic app icon               |
| `assets/adaptive-icon.png`    | 1024 × 1024 | Android adaptive icon **foreground** (transparent BG) |
| `assets/splash.png`           | 2048 × 2048 | Splash screen art                             |
| `assets/favicon.png`          | 196 × 196   | Web favicon                                   |

Visual direction is locked in [`brand-guide.md`](./brand-guide.md). Composition: obsidian background, gold-core / violet-halo / blue-ring orb, hairline gold ring, sparse particle field.

## Forbidden marketing copy

Never use:
- "scientifically proven aura"
- "100% accurate" / "absolute accuracy"
- "biometric identity verification"
- "detects mental illness"
- "predicts your destiny"
- "medical diagnosis" / "psychological diagnosis" / "is a diagnosis" / "provides diagnosis"
- "guaranteed result"
- "bad person"

`npm run verify:release` greps for affirmative misuses of these phrases (denials like "not a diagnosis" are explicitly whitelisted) and fails the build if it finds any.
